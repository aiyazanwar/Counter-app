# 🔢 Counter App

A simple, clean, and interactive Counter App built using core frontend technologies. This is one of my beginner-level projects created to practice JavaScript DOM manipulation and styling concepts.

---

## 🚀 Features
- **Increment (+):** Increases the counter value.
- **Decrement (-):** Decreases the counter value.
- **Reset (0):** Resets the counter back to zero.
- Clean and responsive UI layout.

---

## 🛠️ Technologies Used
- **HTML5:** For structuring the app layout.
- **CSS3:** For styling, colors, and smooth interface design.
- **JavaScript (ES6):** For handling the click events and counter logic.
